# 리프팅 코치

폰 카메라로 리프팅을 찍으면 터치를 세고 자세를 코칭해 주는 웹앱이에요.

**▶ 열기: https://1q223e4r.github.io/lifting-coach/**

## 쓰는 법

1. 폰을 바닥이나 거치대에 세우고 2~4m 떨어져요. 머리부터 발끝, 공까지 다 나오게요.
2. **카메라로 시작**을 누르고 카메라를 허용해요.
3. 화면에서 공을 한 번 탭하고 리프팅을 시작해요.

카메라 없이 화면만 보고 싶으면 **데모 보기**를 눌러요. 찍어 둔 영상은 **영상 올려서 분석**으로 볼 수 있어요.

영상은 폰 안에서만 분석되고 어디에도 올라가지 않아요.
