# 복싱 코치

섀도복싱을 폰 카메라로 찍으면 펀치를 세고, 가드·회수·턱·스탠스를 바로 말로 알려 주는 웹앱이에요.

**▶ 열기: https://1q223e4r.github.io/lifting-coach/**

## 쓰는 법

1. 폰을 가슴 높이에 세우고 2~3m 뒤로 가요. 머리부터 발끝까지 나오게요.
2. **카메라로 시작** → 스탠스·라운드 고르기 → **라운드 시작**. 10초 뒤 공이 울려요.
3. 섀도복싱. 문제가 반복되면 바로 말해 주고, 라운드가 끝나면 펀치 수와 가장 많이 나온 문제를 알려 줘요.

카메라 없이 화면만 보려면 **데모 보기**, 찍어 둔 영상은 **영상 올려서 분석**을 눌러요.

## 보는 것

| 항목 | 재는 방법 | 믿을 만한 정도 |
|---|---|---|
| 펀치 수·종류(잽, 스트레이트, 훅, 어퍼컷) | 팔꿈치 높이, 화면에 보이는 팔 길이, 아래팔 방향, AI 깊이 추정 | 합성 데이터로만 검증. 실제 영상 확인 전 |
| 칠 때 반대손 가드 | 안 치는 손의 주먹 높이 | 높음 |
| 쉴 때 가드 높이 | 주먹이 턱 높이보다 아래인지 | 높음 |
| 회수 속도 | 뻗은 뒤 60% 돌아올 때까지 걸린 시간 | 보통 |
| 턱 들림, 팔꿈치 벌어짐, 발 좌우 간격 | 코·귀 높이, 팔꿈치 위치, 두 발목 간격 | 보통 |
| 스트레이트 몸통 회전, 무릎 굽힘 | AI 깊이 추정 | 참고용 |

영상은 폰 안에서만 분석되고 어디에도 올라가지 않아요.

## 파일

| 파일 | 내용 |
|---|---|
| index.html | 배포되는 앱 전체. `python3 build.py`가 src/를 합쳐서 만들어요 |
| src/core.js | 분석 엔진(펀치 감지, 자세 체크, 라운드 타이머, 데모용 합성 복서) |
| src/app.js | 카메라·영상·데모 흐름, 화면 표시, 공 소리·음성 |
| src/style.css, src/markup.html | 디자인과 화면 구조 |
| tests/ | `node tests/unit.js`, `node tests/eval.js`(합성 데이터로 감지율 확인) |
